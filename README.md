# 抖音作品批量下载器（Windows 桌面端）

自动解析抖音作品链接 → 去水印高清原画 → 自动命名 → 落库管理 → 一键导出 Excel。

> 所有下载均为**去水印、高清原图/原视频、不降质**：视频取最高码率原画，图集保留全原图，实况照片存为 mp4。

## 二、环境准备

- **Python** 3.12 / 3.13
- 安装依赖：`pip install -r requirements.txt`
  - 含 `gmssl`（用于内置 `a_bogus` 签名，纯 Python 实现）
- **无需 Node.js、无需任何签名文件**

## 三、签名说明（已内置，无需配置）

抖音 Web 接口带反爬签名 `a_bogus`。本项目已内置**纯 Python 实现**
（`src/abogus.py`，源自开源项目 TikTokDownloader，依赖 `gmssl`）：

- 不需要 Node.js
- 不需要放置任何 `abogus.js` 文件
- 只需 `pip install gmssl>=3.2.2`（已写入 `requirements.txt`）

若 `gmssl` 未安装，启动/签名时会**明确报错**提示安装，不会静默用错签名
（避免误判为 Cookie 失效）。抖音算法升级导致签名失效时，更新 `src/abogus.py`
重新打包即可。

## 四、Windows 打包（生成 exe）

在本机 Windows 上（Linux 沙箱无法跨平台出 exe）：

```bat
cd /d D:\douyin_downloader
pip install -r requirements.txt
python build\build_windows.py
```

产物：`dist\抖音作品批量下载器.exe`（单文件、无控制台）。

## 五、使用

1. 双击 exe → 首次弹窗选下载路径（需求④）。
2. 「设置」页填抖音网页版 Cookie（需求⑥）；「运行设置」里可调并发下载数。
3. 「下载」页粘贴链接：可直接粘贴抖音 App「分享」复制出的**整段文案**（自动识别链接），
   也可每行一个链接批量粘贴 → 解析 → 弹备注 → 下载（需求①②⑨）。
   - 若下载目录已存在**同名作品文件**，会弹窗询问是否覆盖重下；否则直接下载。
4. 「账户」页卡片点开二级菜单编辑全字段（需求⑤），可「导出 Excel」（需求③）。
5. 「日志」页可「导出运行日志」；「设置」页可导入/导出全量配置(zip)（需求⑦）。

## 六、账户作品保存规则（下载落盘）

默认下载路径下，按以下规则组织文件与文件夹（文件夹名中的 `x` 为对应作品数量）：

| 场景 | 保存位置 | 文件夹/文件命名 |
|------|----------|----------------|
| 同时批量下载同一账号的多个视频 | 合并到 `昵称_抖音号_作品数量共x个` 文件夹 | `备注-昵称-抖音号-发布时间-视频-描述.mp4` |
| 非同时下载的同账号第二个作品 | 弹窗询问「是否合并保存至同一文件夹」；合并后移到 `昵称_抖音号_作品数量共x个` 文件夹 | 同上 |
| 图集（多张图片） | 独立 `昵称_抖音号_图片数量共x个` 文件夹（x=图片数） | `备注-昵称-抖音号-发布时间-图集-描述_1.jpg` … |
| 单个视频 | 不建文件夹，直接放在默认下载路径根目录 | `备注-昵称-抖音号-发布时间-视频-描述.mp4` |

- **文件命名**：`备注（无备注则为空）-昵称-抖音号-作品发布时间-视频/图集/实况照片-详细文字描述`。
- **合并移动**：选择合并后，该账号下全部已下载作品（视频与图集）会被移动到统一文件夹，旧目录自动清理。
- 若后续该账号仍有作品下载，仍按上述「是否合并」弹窗处理。

## 六·二、账户页补充规则

- **主页/分享链接自动匹配**：编辑账号时，若「主页/分享链接」为空，系统会按账号的
  `sec_uid → 抖音号 → UID` 自动推导并补全抖音网页主页链接（`https://www.douyin.com/user/{标识}`），
  点「保存」即写入。下载产生记录时如 API 未返回链接，也会一并自动补全。
- **备注红色字体**：账号列表中，若某账号填写了备注，备注文字以**红色加粗**显示；
  无备注则维持原样（显示「—」），不做任何变动。

## 七、测试

```bat
pip install pytest
pytest tests/ -q
```

GUI 测试在 `QT_QPA_PLATFORM=offscreen` 下运行，无需显示器。

## 八、限制与合规

- 解析/下载依赖有效抖音 Cookie，**仅用于你有权下载的内容**，遵守平台规则与相关法律。
- 签名算法随抖音版本升级可能失效，需更新 `src/abogus.py`。
